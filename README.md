# 📖 Sobre o Projeto

A **Henrique Store** é uma landing page desenvolvida para simular a página inicial de uma loja virtual, apresentando produtos de forma organizada, moderna e intuitiva.

O projeto teve como objetivo colocar em prática conceitos de desenvolvimento Front-end, utilizando tecnologias nativas da web para construir uma interface agradável, responsiva e de fácil navegação.

---

# ✨ Funcionalidades

- 🛒 Página inicial de uma loja virtual;
- 📦 Exibição organizada de produtos;
- 🎨 Interface moderna e atrativa;
- 📱 Layout responsivo;
- ⚡ Navegação intuitiva;
- 💻 Código organizado e de fácil manutenção.

# ⚙️ Como executar

Clone este repositório:

```bash
git clone https://github.com/Henrique-Wandersee/Henrique-Store.git
```

Entre na pasta do projeto:

```bash
cd "Henrique Store"
```

Abra o arquivo **index.html** diretamente no navegador.

Caso utilize o Visual Studio Code, recomenda-se executar o projeto utilizando a extensão **Live Server**.
